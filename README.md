# Advanced Select Dropdown - پروژه React/Next.js

این پروژه یک **کامپوننت Select Dropdown پیشرفته** با امکانات زیر است:

- استفاده از **Headless UI (Listbox)**
- استایل با **Tailwind CSS**
- **جستجو در آیتم‌ها**
- **انتخاب چندتایی**
- **گروه‌بندی آیتم‌ها**
- گزینه‌های **انتخاب همه / هیچ**
- نمایش تعداد آیتم‌های انتخاب شده
- **مجازی‌سازی** برای لیست‌های بزرگ

---

## پیش‌نیازها

- Node.js نسخه پایدار (>=18)
- npm یا yarn
- Next.js 13+  

---
npm install
# یا

npm run dev
# یا
yarn dev
